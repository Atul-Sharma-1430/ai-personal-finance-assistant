# 💰 AI Personal Finance Assistant

An AI-powered **Personal Finance Assistant Chatbot** that uses the **Gemini API** to answer finance-related questions through a simple and interactive web interface.

The chatbot is designed specifically for financial queries and can provide explanations and general guidance on topics such as personal finance, investing, banking, financial markets, trading concepts, and more.

## ✨ Features

- 🤖 Gemini-powered AI responses
- 💬 Natural-language conversation
- 💰 Finance-focused chatbot
- 🧠 Understands a wide range of financial questions
- 🔄 Maintains conversation context during the session
- 🚫 Rejects clearly non-financial questions
- 🌐 Browser-based interface
- ⚡ Real-time AI responses
- 📱 Responsive and clean UI
- 🔐 API key stored securely using environment variables

## 🛠️ Technologies Used

- Python
- Flask
- Google Gemini API
- HTML5
- CSS3
- JavaScript
- python-dotenv
